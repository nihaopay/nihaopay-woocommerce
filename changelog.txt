= NihaoPay Gateway for WooCommerce Changelog =

== English Version ==

== 1.0.4 - 2026-11-02 ==
* Enhancement: General gateway plugin security enhancements

== 1.0.2 - 2025-04-25 ==
* Enhancement: Payment method UI optimization with icons and option areas vertically aligned
* Enhancement: Payment options display improved to show inline for better appearance
* New: Added payment method enable/disable options for admin to control each payment channel individually
* Enhancement: Improved Chinese character URL encoding handling
* Fix: Enhanced session data processing

== 1.0.1 - 2023-10-15 ==
* Fix: Resolved display issues on mobile devices
* Fix: Fixed incorrect amount calculations for certain currencies
* Enhancement: Added better error handling
* Enhancement: Optimized payment flow user experience

== 1.0.0 - 2023-05-01 ==
* Initial release
* Support for AliPay payment
* Support for WeChatPay payment
* Support for UnionPay payment
* Support for multiple currencies: USD, GBP, HKD, JPY, EUR, CAD, CNY
* Test and production environment configuration
